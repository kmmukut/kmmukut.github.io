Resources & Tools

A collection of open-source software I have developed, along with curated tutorials and guides for CFD, coding, and academic writing.

My Software

PyPack

Molecular System Builder

A Python toolkit for building molecular simulation systems. Simplifies the creation of complex packings for LAMMPS/MD simulations.

View on GitHub

MAFIA-MD

Post-Processing Tool

A tool for analyzing molecular structures formed during reactive MD simulations. Isolates aromatics, ring statistics, and fringe identification.

View on GitHub

StereoFractAnalyzer

Fractal Analysis

Python package for analyzing the fractal dimension of 3D surfaces and 2D images. Useful for material science and surface morphology.

View on PyPI

ChronoCode

Security Tool

A lightweight, open-source 2FA/TOTP generator. Available as a PWA and browser extension for secure authentication.

Launch App

Air Quality Viz

Data Visualization

Interactive dashboard monitoring air quality near Marquette University Engineering Hall. Visualize live sensor data.
